# Recovered real headset transcripts

Imported two ASR outputs from one saved headset recording. Synthetic comparison rows are excluded. Candidate labels describe the recognised text, not verified physical actions or independently transcribed speech. Neither candidate is human reviewed.

These are development examples only. They are not an independent test set and have not been used for training. A speaker/session-separated evaluation requires more real recordings. The latest WAV may have been overwritten since the comparison; its historical identity is not established.
